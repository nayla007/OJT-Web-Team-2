# OJT-Web-Team-2

Website proyek OJT yang dibuat menggunakan React + Vite.

---

## Tentang Proyek
Template ini menggunakan setup React + Vite untuk pengembangan cepat dengan HMR dan dukungan ESLint.

Dua plugin resmi yang tersedia:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) – menggunakan [Babel](https://babeljs.io/) untuk Fast Refresh.
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) – menggunakan [SWC](https://swc.rs/) untuk Fast Refresh.

---

## React Compiler
React Compiler belum diaktifkan di template ini karena dapat mempengaruhi performa saat pengembangan & build.  
Untuk menambahkannya, lihat [panduan resmi](https://react.dev/learn/react-compiler/installation).

---

## Catatan
Template ini dapat dikembangkan lebih lanjut sesuai kebutuhan proyek OJT-Web-Team-2.
